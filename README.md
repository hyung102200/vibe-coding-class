# 자취생활 실태 설문조사 🧾

자취/독립생활 실태를 조사하는 설문조사 웹앱입니다. Google Apps Script(GAS)로 구동되며, 응답 데이터는 Google Sheets에 저장됩니다.

편의점 영수증에서 영감을 받은 디자인으로, 상단의 바코드 스캔 애니메이션과 계산대 LED 카운터가 응답 진행 상황을 보여줍니다.

## 미리보기

| 설문 화면 | 완료 화면 |
|---|---|
| 영수증 스타일 문항 리스트 | "PAID" 도장 애니메이션 |

## 주요 기능

- **영수증 컨셉 UI** — 톱니모양 절취선, 점선 구분선, 바코드/QR 장식 등 편의점 영수증을 모티프로 한 디자인
- **실시간 진행률 표시** — 상단 바코드 스캔 바 + LED 숫자 카운터가 답변할 때마다 갱신
- **다양한 응답 유형 지원** — 단일선택, 복수선택(체크박스), 5점 척도(키패드 스타일)
- **Google Sheets 연동** — 별도 백엔드 서버 없이 GAS만으로 응답 데이터 저장
- **모바일 최적화** — 좁은 화면 기준으로 반응형 레이아웃 구성

## 설문 문항

| 번호 | 항목명 | 질문 | 응답 유형 |
|---|---|---|---|
| 1 | 독립기간 | 현재 자취(독립생활) 기간은 얼마나 되나요? | 단일선택 |
| 2 | 거주형태 | 현재 거주 형태는 어떻게 되나요? | 단일선택 |
| 3 | 월생활비 | 월 평균 생활비(주거비 제외)는 어느 정도인가요? | 구간선택 |
| 4 | 주거비부담도 | 월세·관리비 등 주거비 부담을 어떻게 느끼시나요? | 5점 척도 |
| 5 | 자취애로사항 | 자취 중 가장 어려운 점은 무엇인가요? | 복수선택 |
| 6 | 만족도 | 자취 생활에 대한 전반적인 만족도는 어느 정도인가요? | 5점 척도 |

1·2번 문항은 필수 응답이며, 나머지는 선택 응답입니다.

## 기술 스택

- **Google Apps Script (GAS)** — 백엔드 및 웹앱 호스팅
- **HTML / CSS / Vanilla JS** — 프론트엔드 (외부 프레임워크 없음)
- **Google Sheets** — 응답 데이터 저장소

## 폴더 구조

```
.
├── Code.gs        # GAS 백엔드 (웹앱 라우팅, 시트 저장 로직)
├── index.html     # 설문 폼 + 완료 화면 (단일 HTML)
└── README.md
```

## 설치 및 배포 방법

1. [Google Apps Script](https://script.google.com)에서 새 프로젝트를 생성합니다.
2. 이 저장소의 `Code.gs`, `index.html` 내용을 각각 같은 이름의 파일로 붙여넣습니다.
   - `index.html` 파일명은 반드시 `index`여야 합니다.
3. 응답을 저장할 Google 스프레드시트를 새로 만들고, 첫 번째 탭 1행에 아래 순서로 헤더를 입력합니다.

   ```
   독립기간 | 거주형태 | 월생활비 | 주거비부담도 | 자취애로사항 | 만족도
   ```

4. `Code.gs` 상단의 `SHEET_URL` 값을 만든 스프레드시트 주소로 교체합니다.

   ```javascript
   var SHEET_URL = 'https://docs.google.com/spreadsheets/d/여기에_스프레드시트_ID를_입력하세요/edit';
   ```

5. 상단 메뉴에서 **배포 > 새 배포**를 선택합니다.
6. 유형을 **웹 앱**으로 선택하고, 실행 계정과 액세스 권한을 설정한 뒤 배포합니다.
7. 발급된 웹앱 URL로 접속하면 설문 페이지가 열립니다.

## 데이터 저장 방식

- 응답 제출 시 `google.script.run`을 통해 `Code.gs`의 `submitForm(data)` 함수가 호출됩니다.
- 복수선택 문항(자취애로사항)은 선택된 값들을 쉼표(`, `)로 이어붙여 한 셀에 저장됩니다.
- 저장 성공/실패 여부는 클라이언트에 반환되어, 실패 시 에러 메시지가 화면에 표시됩니다.
